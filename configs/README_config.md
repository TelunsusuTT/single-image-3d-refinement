# Configs

This directory holds project-local copies of Hunyuan3D-Paint configs.

`scripts/prepare_official_overfit_config.sh` copies the official upstream paint config from:

```bash
/vol/bitbucket/ct1022/Hunyuan3D2.1_Work/hy3dpaint/cfgs/hunyuan-paint-pbr.yaml
```

to:

```bash
/vol/bitbucket/ct1022/hy3dpaint_finetune/configs/ft_overfit_official.yaml
```

Edit only the project-local copy. Do not edit the upstream config.
